GridVision OpenDSS - HOW TO RUN

1. Extract this ZIP to your Desktop (Right-click > Extract All)
2. Open the folder named package_windows
3. Double-click:  1_START_HERE.bat
4. Wait until you see "Starting web server"
5. Browser opens at http://127.0.0.1:8000/
6. Keep the black window open

If bat closes immediately or fails:
- Open 2_MANUAL_CMD_INSTRUCTIONS.txt and follow it
- Or send us the file run_log.txt from this folder

Need Python 3.10+ from python.org with "Add to PATH" checked.
